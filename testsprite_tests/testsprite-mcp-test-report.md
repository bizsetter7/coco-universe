## 3. 발견된 버그 상세

### 🔴 [BUG-01] 성인인증 오버레이 '성인인증없이 나가기' 버튼 무작동 (Critical)

**영향 TC:** TC015, TC016, TC018, TC022, TC024, TC025, TC031, TC035, TC036, TC037, TC039 (11건)

**현상:**
- `/jobs`, `/community`, `/customer-center` 접근 시 성인인증 오버레이가 표시됨
- `'성인인증없이 나가기'` 버튼 2회 클릭해도 오버레이가 닫히지 않음
- ESC 키도 효과 없음
- 오버레이가 페이지 콘텐츠 전체를 가림

**비고:** 일부 테스트(TC020, TC021, TC023, TC026)는 동일 페이지에서 성공 → 오버레이 표시가 세션 상태/쿠키에 따라 간헐적으로 발생하는 것으로 추정

**조치 필요:**
`'성인인증없이 나가기'` 버튼의 onClick 핸들러 동작 확인 및 수정. 클릭 시 오버레이 상태(state)가 실제로 닫힘 처리되는지 재검토.

---

### 🔴 [BUG-02] 광고 등록 폼 — '선택한 상품 신청하기' 클릭 후 DOM 비어짐 (Critical)

**영향 TC:** TC028, TC029, TC031, TC032 (4건)

**현상:**
- `/my-shop`에서 상품 선택 후 `'선택한 상품 신청하기'` 클릭 시 페이지 DOM이 완전히 비어짐 (0 interactive elements)
- 광고 등록 4단계 폼이 열리지 않음
- keepalive ping timeout(error 1011) 발생

**조치 필요:**
광고 등록 폼 렌더링 트리거 로직 점검. `'선택한 상품 신청하기'` 클릭 이벤트 핸들러에서 폼 상태 초기화 또는 라우팅이 정상 작동하는지 확인.

---

### 🔴 [BUG-03] 마이샵 — '광고 등록' 진입 버튼 없음 (High)

**영향 TC:** TC030, TC034 (2건)

**현상:**
- `test_shop`(기업회원)으로 로그인 후 `/my-shop` 접근 시 `'광고 등록'` 버튼/링크가 없음
- `'광고등록안내'` 정보성 링크만 존재하고 실제 등록 폼 진입 불가

**조치 필요:**
기업회원 로그인 후 마이샵 페이지에서 광고 등록 진입점(버튼/링크) 노출 여부 확인.

---

### 🟡 [BUG-04] 카테고리 필터 — 선택해도 비해당 광고 표시 (Medium)

**영향 TC:** TC017 (1건)

**현상:**
- `'카페'` 카테고리 선택 클릭해도 목록에 `'룸싸롱'`, `'셔츠룸'`, `'노래주점'` 등 비-카페 광고가 그대로 표시됨
- 필터 선택 상태 표시 없음, UI 피드백 없음

**조치 필요:**
카테고리 필터 선택 시 실제 필터링 로직(상태 업데이트 → 목록 재조회) 동작 확인.

---

### 🟡 [BUG-05] 헤더 — 로그인 후 마이샵/즐겨찾기 링크 미노출 (Medium)

**영향 TC:** TC013, TC014 (2건)

**현상:**
- 로그인 후 헤더에서 `'마이샵'`, `'즐겨찾기'` 네비게이션 링크를 찾을 수 없음
- 헤더 프로필 클릭 시 알림함 팝업만 열림 (`로그아웃`은 노출됨)

**조치 필요:**
로그인 상태에서 마이샵/즐겨찾기 링크가 헤더에 노출되도록 UI 수정.

---

### 🟡 [BUG-06] 광고 상세 — '신고' 버튼 클릭 불가 (Medium)

**영향 TC:** TC027 (1건)

**현상:**
- 광고 상세 모달에서 `'신고'` 텍스트는 있지만 인터랙티브 요소(버튼/링크)로 인식되지 않음
- 클릭 가능한 인덱스 없음, 신고 기능 동작 불가

**조치 필요:**
`'신고'` 텍스트에 버튼 또는 클릭 핸들러 연결 확인.
