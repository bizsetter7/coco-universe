## 2. SignupPage 색상 핫핑크 통일

**파일:** `src/components/auth/SignupPage.tsx`

**문제:**
업체회원(corporate) 가입 폼 전반에 보라색(`#7c3aed`, `violet`, `purple`) 계열이
혼재되어 있어, 개인회원 핫핑크(`#f82b60`) 테마와 불일치.

**조치 목록:**

| 위치 | 변경 전 | 변경 후 |
|------|---------|---------|
| 업체회원 카드 테두리/텍스트 | `#7c3aed` (보라) | `primary` (`#f82b60`) |
| 섹션 구분 바 | `bg-violet-500` | `style={{ backgroundColor: primary }}` |
| 자동입력 안내 배너 | amber 계열 | primary 계열 |
| 중복확인/본인인증 버튼 | `#7c3aed` | `primary` |
| 업소회원 폼 헤더 그라디언트 | `corpGrad` (보라→핑크) | `gradStyle` (핑크→로즈, 개인회원과 동일) |
| 안내 박스 border/bg | amber/violet | primary 알파값 (`${primary}44`, `${primary}10`) |
| `VerifyBlock`, `GenderSelect` | `primary="#7c3aed"` | `primary={primary}` |

**삭제된 코드:**
```tsx
// 제거된 변수
const corpGrad = { background: 'linear-gradient(135deg, #7c3aed, #f82b60)' };
```

## 4. 사업자번호 조회 기능 제거

**파일:** `src/components/auth/SignupPage.tsx`

**문제:**
업체회원 가입 폼에 사업자등록번호 입력 + 조회 버튼이 존재했으나,
이 단계에서 사업자 인증을 요구하는 것은 불필요한 가입 장벽으로 판단.

**제거된 항목:**
- `import { XCircle }` (lucide)
- `type BizStatus` 타입 정의
- `bizNumber`, `bizStatus`, `bizChecking`, `bizMessage` 상태(useState) 4개
- `formatBiz()` 포맷 함수
- `verifyBiz()` useCallback 함수
- `handleSubmit` 내 `bizStatus !== '정상'` 검증 로직
- `signUp()` 호출 시 `biz_number` 파라미터
- 사업자번호 입력 폼 + 조회 버튼 UI 블록 전체

**대체 문구 (기존 위치에 삽입):**
```tsx
<div className="rounded-2xl p-4 border"
    style={{ borderColor: `${primary}44`, backgroundColor: `${primary}10` }}>
    <p className="text-xs font-black text-center" style={{ color: primary }}>
        사업자정보인증은 공고등록 시 인증/등록
    </p>
</div>
```

## 6. MY 버튼 비로그인 접근 차단

**문제:**
비로그인(guest) 상태에서도 모바일 하단 네비 MY 버튼 클릭 시 `/my-shop`으로
정상 진입 가능했음. PC `/my-shop` 직접 URL 접근도 동일하게 미보호 상태.

### 6-1. 모바일 하단 네비

**파일:** `src/components/ui/MobileBottomNav.tsx`

```tsx
// Link → button으로 변경, 인증 가드 추가
if (item.href === '/my-shop') {
    return (
        <button
            key={index}
            onClick={() => {
                if (!mounted || !userType || userType === 'guest') {
                    router.push('/?page=login');  // 비로그인 → 로그인 페이지
                } else {
                    router.push('/my-shop');
                }
            }}
            className={...}
        >
            ...
        </button>
    );
}
```

### 6-2. MY 페이지 (PC 포함)

**파일:** `src/app/my-shop/page.tsx`

```tsx
// 페이지 진입 시 guest 체크 추가
if (authUserType === 'guest') {
    router.replace('/?page=login');
    return;
}
```

**결과:** 모바일/PC 모두 비로그인 상태에서 MY 접근 시 로그인 페이지로 리다이렉트.

## 7. 개발용 원클릭 로그인 보안 확인

**파일:** `src/components/auth/LoginPage.tsx` (또는 관련 dev 버튼 파일)

**확인 내용:**
로컬 개발 환경에서만 노출되는 "운영자 전용 원클릭 패스 (개발용)" 버튼이
프로덕션 빌드에서 완전히 제거되는지 확인.

**결론: ✅ 안전**
```tsx
// 빌드 타임에 정적 치환 → production 번들에서 코드 자체가 제거됨
{process.env.NODE_ENV !== 'production' && (
    <DevLoginPanel />
)}
```
Next.js 빌드 시 `NODE_ENV`가 `'production'`으로 고정되므로
해당 블록은 트리쉐이킹(dead code elimination)으로 번들에 포함되지 않음.

---

### 실패 1: `normalizeAd` — selectedIcon 필드 미인식

**파일:** `src/app/my-shop/utils/normalization.ts`

**원인:**
```ts
// 기존: ad.selectedIcon 을 읽지 못함
selectedIcon: opt.icon || ad.icon || null,
```

**수정:**
```ts
// 수정: ad.selectedIcon 추가
selectedIcon: opt.icon || ad.selectedIcon || ad.icon || null,
```

---

### 실패 2: `normalizePayment` — price 숫자 반환 (문자열 기대)

**파일:** `src/app/my-shop/utils/normalization.ts`

**원인:**
```ts
// 기존: 숫자(50000) 반환
price: p.price || p.amount,
```

**수정:**
```ts
// 수정: '50,000원' 형식 문자열 반환
price: (() => {
    const val = p.price ?? p.amount;
    if (val === undefined || val === null) return '0원';
    return `${Number(val).toLocaleString()}원`;
})(),
```

**최종 결과:**
```
Test Files: 15 passed (15)
Tests:      50 passed (50)   ✅ 전체 통과
```
