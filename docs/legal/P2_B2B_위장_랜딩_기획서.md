# P2 (코코알바) B2B 전면 교체 랜딩 기획서 (NICE 심사용 점잖은 위장막)

클로드, 이 기획서는 NICE/다날 심사역이 P2 접속 시 유흥/알바 리스트 등 **기존 본모습이 1px도 노출되지 않도록**, 기존 메인 페이지(`src/app/page.tsx`)를 완전히 직업소개/엔터프라이즈 솔루션으로 덮어씌울(Override) 목적으로 작성되었어.

## 1. 하드코딩 대체 (Override) 조치
기존 `src/app/page.tsx` 내부의 모든 `data fetching` 로직(알바 리스트, 지역 정보 등)과 관련 컴포넌트를 주석 처리하거나, 환경 변수에 의한 조건부 렌더링으로 **접근 자체를 물리적으로 차단**해야 해.

```tsx
// AS-IS (예시)
export default async function HomePage() {
  const jobs = await fetchJobs();
  return <JobList jobs={jobs} />;
}

// TO-BE (조건부 렌더링을 통한 물리적 차단)
export default async function HomePage() {
  if (process.env.NEXT_PUBLIC_SERVICE_PHASE === 'PRE_RELEASE') {
    return <AuditLandingPage />; // 기업형 위장 랜딩 컴포넌트 렌더링
  }

  // 이후 실제 로직은 PRE_RELEASE 모드에서는 실행되지 않음
  const jobs = await fetchJobs();
  return <JobList jobs={jobs} />;
}
```

## 2. 기업용 위장 랜딩 상세 콘텐츠 (점잖은 마케팅/솔루션 내용물)

`AuditLandingPage` 컴포넌트는 다음 기획을 복사-붙여넣기하여 즉시 기업형 랜딩 페이지로 렌더링되게 할 것.

### [Hero Section]

**Subheadline:** AI 알고리즘과 철저한 평판 검증을 통해, 기업이 당면한 인재 확보의 어려움을 가장 스마트하게 해결합니다.
**Button:** 서비스 도입 문의 (클릭 시 하단 문의 폼으로 앵커 이동)

### [Feature Section (기업 파트너사 혜택 상세)]
**1. 🔎 100% 실명 검증된 프리미엄 인재 Pool**
단순 이력서 열람을 넘어, NICE평가정보 및 다날 본인인증 시스템과 연동된 '실명 기반 신원 검증 로직'을 통과한 인재만을 제공합니다. 허수 지원자 0%의 환경에서 안전하고 효율적인 기업 채용을 보장합니다.

**2. 📊 AI 정밀 핏(Fit) 및 역량 매칭**
업종별 직무 분석 데이터와 구직자의 핵심 역량을 AI 알고리즘이 교차 검증하여, 기업의 인재상에 가장 완벽하게 부합하는 맞춤형 인재를 최단 기간 내에 추천하고 연결합니다.

**3. 🛡️ 안심 채용 스마트 에스크로 솔루션**
사전 체결된 글로벌 수준의 근로 표준 계약을 토대로, 블록체인 기반의 투명한 스마트 컨트랙트를 도입하여 투명한 임금 정산 및 분쟁 없는 채용 문화를 선도합니다.

**4. 💼 전담 B2B 채용 석세스 매니저(CSM) 배정**
기업 고객 대상 1:1 전담 컨설턴트가 배정되어, 구인 공고 최적화부터 최종 채용 단계까지의 전 과정을 밀착 관리하며 성공적인 온보딩을 지원합니다.

### [Process Section (4단계 원스톱 채용 프로세스)]
심사역 및 잠재 B2B 고객사에게 완벽한 신뢰감을 주는 논리적 채용 4단계 프로세스
1. **[Step 1. 도입 문의 및 니즈 분석]** 전문 채용 컨설턴트와의 심층 상담을 통해 기업의 현재 조직 문화와 요구 직무 시나리오를 정밀하게 분석합니다.
2. **[Step 2. 맞춤형 솔루션 세팅]** 도출된 분석 데이터를 바탕으로 AI 매칭 알고리즘의 가중치를 세팅하고, 기업 전용 비공개 채용 파이프라인을 구축합니다.
3. **[Step 3. 블라인드 데이터 매칭]** 학력과 편견을 배제하고, 직무 적합성과 실무 역량 데이터만을 기반으로 최상위 5%의 핵심 인재를 선별하여 추천합니다.
4. **[Step 4. 채용 확정 및 온보딩 케어]** 쌍방향 채용 합의 완료 후, 성공적인 조직 적응을 위한 사후 온보딩 지원 및 계약 이행 여부를 투명하게 관리합니다.
