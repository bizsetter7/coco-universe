# P2 스위칭 시나리오 및 심사용 코드 정화 기획서 (NICE 심사 대응)

클로드, 이 문서는 P2(코코알바)가 심사역에게 완벽한 B2B 솔루션으로 보이게끔 코드를 정화(Sanitization)하고, 심사 통과 즉시 본모습으로 1초 만에 돌아올 수 있는 **환경 변수 기반 스위칭 로직**을 가이드하기 위해 작성되었어.

## 1. 브랜드 전환 스위치 (Transition Switch) 설계안
심사용 코드와 본체 코드를 분리 배포하는 것은 위험해. 단일 코드베이스에서 Vercel 환경 변수만 조작하여 전체 사이트의 성격을 즉시 바꿀 수 있도록 로직을 세팅해.

**[환경 변수 정의]**
- `NEXT_PUBLIC_SERVICE_PHASE` : 현재 서비스의 비즈니스 단계를 정의 (의심스러운 단어 사용 금지)
  - `PRE_RELEASE` : B2B 솔루션 위장막 모드 (심사용)
  - `PRODUCTION` : 코코알바 전체 서비스 개시 (본모습)

**[글로벌 설정 통합 (config.ts 예시)]**
```typescript
// src/lib/config.ts
export const isPreRelease = process.env.NEXT_PUBLIC_SERVICE_PHASE === 'PRE_RELEASE';

export const SERVICE_INFO = {
  TITLE: isPreRelease ? '초코파트너스 B2B | 맞춤형 인재 매칭 솔루션' : '코코알바 | 여성전문 고소득 알바 No.1',
  DESCRIPTION: isPreRelease 
    ? '기업 성공을 위한 최적의 인재 매칭 B2B 솔루션입니다. 검증된 파트너 네트워크를 제공합니다.' 
    : '지역 기반 100% 실명 인증, 가장 확실하고 안전한 고소득 알바 매칭 플랫폼.',
};
```

## 2. 심사용 코드 정화(Sanitization) 전수 검사 리스트 (필수 체크)
심사역이 소스 코드나 Network/Console 탭을 열어보더라도 '코코알바'의 본모습(유흥, 고수익 등)을 유추할 수 없도록 코드를 완벽히 세탁해라.

- [ ] **변수명/함수명 정제**
  - 금지어: `isFake`, `auditMode`, `masking`, `adultOnly`, `nightJob`
  - 권장어: `isPreRelease`, `featureFlag`, `maintenanceMode`, `b2bMode`
- [ ] **메타 데이터(SEO) 및 Title/Description 정화**
  - Next.js의 `metadata` 객체(`layout.tsx` 등)에 유흥/밤알바/여성전용 등의 키워드가 하드코딩되어 있는지 전수 조사하고, `SERVICE_INFO.TITLE`로 교체.
- [ ] **Console.log 및 Network 찌꺼기 제거**
  - `PRE_RELEASE` 모드에서 백엔드의 알바 리스트 API(`api/jobs`)가 무심코 호출되어 Network 탭에 데이터가 찍히지 않는지 확인. (호출 아예 차단)
- [ ] **robots.txt 차단 설정**
  - 심사 기간 동안 구글 봇이 본모습 페이지를 강제 크롤링하지 못하도록 `robots.txt`를 일시적으로 보수적으로 세팅 (`Disallow: /` 권장 - 단서 조항: 심사 직후 풀 것)
- [ ] **API Key 및 Secret 평문 노출 확인**
  - 통합 SOP 5대 보안 원칙에 따라, 심사용으로 임시 구현한 로직 내에 API 키가 프론트엔드에 노출되지 않도록 서버사이드로 은닉됨을 최종 확인.
